# Python 文件分析工具

一个基于标准库的命令行工具，用于递归扫描指定目录中的文件元数据，输出统计结果并生成 CSV 文件清单。

## 主要功能

- 递归扫描指定目录及其子目录。
- 默认跳过任意层级的 `.git` 目录及其全部内容。
- 统计文件总数、不同扩展名的类型数、各扩展名文件数量和文件总大小。
- 将扩展名统一按小写统计；没有扩展名的文件归类为 `[无扩展名]`。
- 在终端显示体积最大的 10 个文件。
- 生成 UTF-8 with BOM 编码的 CSV 文件，方便使用 Windows Excel 打开中文内容。
- 遇到无法读取的文件或目录时跳过，并在终端给出提示。

## 运行要求

- Python 3.10 或更高版本。
- 不需要安装第三方依赖。

## 使用方法

在项目目录中运行命令。

### 交互模式

不传参数时，程序会依次提示输入扫描目录和 CSV 保存路径：

```powershell
python file_analyzer.py
```

提示示例：

```text
请输入要扫描的文件夹路径：
请输入 CSV 文件保存路径：
```

### 命令行模式

通过参数直接指定两个路径：

```powershell
python file_analyzer.py --scan-dir "D:\待扫描目录" --output "D:\输出目录\file_list.csv"
```

`--scan-dir` 和 `--output` 都可以单独省略；程序只会询问缺失的那个值。例如：

```powershell
python file_analyzer.py --scan-dir "D:\待扫描目录"
```

此时程序会提示输入 CSV 保存路径。

## 终端统计结果

扫描成功后，终端会显示：

- 文件总数量；
- 不同文件类型数量；
- 文件总大小（字节和易读单位）；
- 每种扩展名的文件数量；
- 体积最大的 10 个文件及其路径、字节数和易读大小。

## CSV 输出

CSV 文件包含以下列：

| 列名 | 内容 |
| --- | --- |
| 文件名 | 文件的名称 |
| 文件路径 | 文件的绝对路径 |
| 文件扩展名 | 小写扩展名，或 `[无扩展名]` |
| 文件大小（字节） | 文件大小的字节数 |

输出文件使用 `utf-8-sig` 编码（UTF-8 with BOM）。输出文件的父目录必须已经存在，且输出路径必须是一个尚不存在的文件；工具不会覆盖已有文件。

## 安全限制与错误处理

- 扫描过程中只读取文件和目录的元数据，不读取或修改文件内容。
- 不会删除、移动、重命名或修改扫描目录中的原文件。
- 只会尝试创建 `--output` 指定的新 CSV 文件。
- 扫描目录不存在、不是目录或无权读取时，程序会报错并停止。
- 输出目录不存在、输出路径为目录、输出文件已存在或无法写入时，程序会给出清晰错误提示。
- 无法读取的子目录或文件会被跳过，扫描继续进行，并输出跳过提示。

## 运行测试

执行全部自动化测试：

```powershell
python -B -m unittest -v
```

测试覆盖文件统计与 CSV 输出、`.git` 目录排除、交互模式、命令行模式，以及无效扫描或输出路径的处理。
